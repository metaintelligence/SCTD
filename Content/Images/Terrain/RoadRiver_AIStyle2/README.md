# Road / River AI Style 2 Tiles

This folder is a second sample set derived from the approved `RoadRiver_AIStyle` renders.
The built-in image generator returned unrelated infographic/medical images during the new live generation attempt, so this set preserves the accepted style and topology by applying local art-direction variations to the approved images.

- 20 terrain tile variants are in this folder.
- 20 matching topology masks are in `TopologyMasks`.
- `_AIStyle2_ContactSheet.png` is the visual review sheet.

The deterministic topology masks remain the source of truth for exact 3D modeling ports.
